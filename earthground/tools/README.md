# Earthground Tools

## Place With KiCad

Run an Earthground design script, open KiCad, and continuously write a YAML
placement file while you move footprints.

Install Earthground, then run:

```
place_with_kicad your_design.py
```

Optional flags:

```
place_with_kicad your_design.py --output placements.yaml --poll-interval 1.0
```
